### About
This mod is a way better version of "Radar Rect" for PC. This is not a port!

Was made for my cool AML community members: https://discord.gg/2MY7W39kBg

### Features
- Radar shapes: Circle, Rectangle, Rounded, Squircle, Beveled, Leaf, Parallelogram, Triangle, Rhombus, Trapezoid, Pentagon, Hexagon, Octagon and Shield
- Radar X/Y scale, corners rounding and outline
- GTA V styled 3D radar with separate on-foot and in-vehicle tilt, blips and GPS mod route are tilted too
- Always front radar

### Config
All of them are in `RadarShapeR.SA.ini`, the first six are in SAUtils menu too.

| Key | Default | Description |
| --- | --- | --- |
| RadarShapeRounding | 0.5 | How round the shape corners are, 0.0 - 1.0 |
| Radar3D | On | 3D radar |
| Radar3DOnFootTilt | 0.0 | Tilt strength on foot, 0.0 - 0.7 |
| Radar3DVehicleTilt | 0.7 | Tilt strength in a vehicle, 0.0 - 0.7 |
| Radar3DFlatBlips | Off | Lays blips flat instead of keeping them upright |
| Radar3DFrontShift | 0.0 | Always front radar, how far ahead of the player the radar is, 0.0 - 0.6 |
| Radar3DForwardShift | 0.0 | Moves the player down on the tilted radar, -0.6 - 0.6 |
| Radar3DZoom | 1.0 | Extra zoom, 1.0 - 3.0 |
| Radar3DCompensateZoom | On | Widens the radar range, so the tilt does not zoom it in |
| Radar3DBlipDepthScale | 0.0 | How much blips shrink with a distance, 0.0 - 1.0 |
| RadarExtendedStreaming | On | Loads more radar sections when the tilt needs them |
| Radar3DHideOffRadarBlips | On | Hides other mods' blips stuck at the radar edge |
| Radar3DDebug | Off | Logs the tilt values |
